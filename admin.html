🚀 النشر المباشر على المتجر (GitHub)

بعد إعداد هذا القسم مرة واحدة، يكفي الضغط على «نشر للعملاء» ليظهر كل تعديل في المتجر خلال دقيقة تقريباً، دون رفع ملفات يدوياً.

كيف أحصل على المفتاح؟
  1. ادخل GitHub ← صورتك ← Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  2. في Repository access اختر Only select repositories ثم مستودع المتجر فقط.
  3. في Permissions ← Repository permissions اجعل Contents = Read and write.
  4. انسخ المفتاح والصقه هنا. يُحفظ في هذا المتصفح فقط ولا يظهر للعملاء.
